# Bouquet Designs per Occasion — Design

Date: 2026-10-17
Status: Approved in conversation ("Yes")

## Goal

Each occasion gets its own bouquet design (shape, not just colour), built in
code with three.js. The current design stays, without its built-in fillers.
If the user dislikes the generated look, the fallback plan is free model files.

## Designs

| key | Name | Occasions | Parts (outer / inner / ribbon) |
|---|---|---|---|
| `classic` | Classic cone | graduation, just_because, legacy | kraft paper / pink paper / ribbon at neck |
| `korean` | Korean layered wrap | romance | outer sheets / inner sheets / bow at neck |
| `hand_tied` | Round hand-tied | wedding | — / — / satin wrap on stems + bow |
| `box` | Flower box | birthday | box / liner / band + bow |
| `basket` | Basket | sympathy | basket / liner / none |

Every design has a **flower bed**: a low moss-green dome filling the opening,
which is what flowers are placed on (clicks, drops, "Fill the rest").

## Shared base builder: `src/utils/bouquetDesigns/`

`createBouquetBase(designKey, { loadGltf, wrapperScale })` →
`{ root, dressing: { outer, inner, applyRibbon(hex|null), wrapMeshes }, targets, defaults }`

- `root` sits on the floor (min y = 0), centred on x/z, about 3.5 units tall
  for classic (generated designs are built at a matching size), then wrapper
  scale applied about the floor centre (`scale *= s`, `position *= s`).
- `outer.apply(hex|null)` / `inner.apply(hex|null)`: null = the design's own colour.
- `targets`: meshes flowers can be placed on (bed + visible parts).
- Used by `FlowerCustomizer.vue` and `3DModelViewer.vue` (orders, cart) so a
  saved bouquet rebuilds identically.

Classic: `public/Boquet.classic.glb`, generated by
`scripts/build-classic-bouquet.mjs` (gltf-transform) keeping only the wrapper
(`paper04_05_06`, `Pink`); falls back to hiding filler meshes in `Boquet.glb`.

## Occasion link

`design` added to each preset (server `BouquetPresets::DEFAULTS` and
`constants/bouquetPresets.js`), returned with presets, saved in the bouquet
customization as `design`. Missing design (old bouquets) → `classic`.

## Tests

- Every generated design builds, has outer/inner/ribbon controls that change
  colour and restore defaults, a non-empty `targets`, sits on the floor, and
  stays under ~400 KB as GLB.
- `designForOccasion` mapping; presets include `design`.
- Browser screenshots of each design.
